# MineOrt IV — пакет документации (разработка и приёмка)

**Статус:** черновик для утверждения, не финальное ТЗ · **Версия пакета:** v0.6 (старт Блока 0, 14.11.2026; раунд 4 финального ревью плана MVP — v0.5; план разработки MVP — v0.4; раунд 3 повторного ревью — v0.3) · **Базовая дата:** 13.11.2026 (пятница) · **Запуск:** 10.12.2026 (четверг), 27 календарных дней.

Пакет превращает [аудит концепции и разработки v2](<MineOrt_IV_Аудит_концепции_и_разработки_v2 (1).md>) (1241 строка, исходный файл не изменялся) в набор рабочих документов: анализ противоречий и пробелов, модель продукта, сценарии, архитектуру, план, тестовые кейсы и каркасы технических заданий. Всё, чего нет в аудите (числа, механизмы, даты, варианты по умолчанию), помечено [ПРЕДЛОЖЕНИЕ КОМАНДЫ] и не считается утверждённым, пока владелец не сменит статус решения в [реестре OD](00-analysis/03-open-decisions.md). Тексты правил сервера в пакете не придумывались (OD-06).
